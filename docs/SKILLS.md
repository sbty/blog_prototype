# Documentation routing

- Current behavior is described by `current-architecture.md` and
  `current-invariants.md`; read them only for architecture/invariant work.
- For Blogger operations use `multi-blog-operations-runbook.md` and the matching
  checklist. Phase documents apply only to that phase.
- `adr/` is historical evidence. Open only an ADR directly relevant to a disputed
  decision; never read the whole directory by default.
- Update docs only when user-visible operation, architecture, or an invariant
  changes. Keep examples concise and link to source rather than duplicating it.
