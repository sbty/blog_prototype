# 8ブログ共通の運用チェックリスト

このチェックリストは [運用Runbook](./multi-blog-operations-runbook.md) の簡易版である。いずれかが未確認なら、その投稿を変更または公開しない。

## 変更前

- [ ] 対象ブログの `blogKey`・blog ID・投稿ID・slugをローカル正本と照合した。
- [ ] 対象投稿の下書き/予約/公開状態と、同一タイトルの重複を読み取った。
- [ ] `data/STOP` が無く、今回の操作だけに対応するフラグとブログ許可リストを確認した。
- [ ] 本文、公式情報リンク、ラベル、検索説明、パーマリンク、画像方針が監査済み正本にある。
- [ ] 予約操作では、承認・readiness・preview・ハッシュ監査・明示確認を完了した。

## 保存・画像追加の直後

- [ ] タイトル、本文、公式情報リンク、ラベル、検索説明、パーマリンクを正本と照合した。
- [ ] 画像は0枚または意図した1枚のみで、二重挿入がない。
- [ ] 「その他のオプション」→「保存」または有効な保存ボタンを使い、保存完了を確認した。
- [ ] `audit-existing-draft` を新しい出力先で実行し、新しいブラウザコンテキストで画像・本文・設定が残っていることを確認した。
- [ ] 複数記事では `audit-existing-draft-batch` を使い、投稿ID・編集URL・出力先の重複がないことを事前検証した。
- [ ] バッチ集計のFAIL記事だけを修復候補として分離し、PASS記事は変更しない。
- [ ] 下書き状態であり、意図しない予約・公開がない。

## 予約直後

- [ ] 投稿ID、ブログキー、タイトル、本文、画像、公式リンク、ラベル、検索説明、パーマリンクが予約前と一致する。
- [ ] Blogger上の予約状態とJSTの予定日時が承認済みカレンダーと一致する。
- [ ] 同一ブログの同日上限、同時刻、既存予約との衝突がない。
- [ ] 読取不能は `UNVERIFIED` として分離し、前回 `UNVERIFIED` と同じ対象だけを限定再監査する。
- [ ] パーマリンク修復準備は、現在値が空で他の全監査項目がPASSの投稿だけを候補にする。別slug、正本差分、接続不能は除外する。

## 公開後（予定時刻の30分後以降）

- [ ] 公開済み状態、公開日時（JST）、公開URL、投稿IDを記録した。
- [ ] 公開ページでタイトル、本文、画像1枚、公式情報リンクが表示される。
- [ ] 編集画面または正本照合で、ラベル、検索説明、パーマリンクを確認した。
- [ ] 同一タイトルまたは投稿IDの重複公開がない。
- [ ] 記事ごとのPASS/FAILと根拠を日別・集計レポートへ記録した。

## FAIL時

- [ ] それ以上の変更、再保存、再予約、再公開、削除を止めた。
- [ ] スクリーンショット、HTML診断、投稿ID、状態、理由を保存した。
- [ ] 問題記事だけを別の修復対象として分離し、再試行には明示承認を求めた。
